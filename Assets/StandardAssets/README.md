# Standard Assets (Unity Legacy, Free)

This folder contains the **Aircraft** vehicle assets from Unity's legacy Standard Assets package (propeller plane meshes, materials, prefabs). They are included for visualization only.

- Source: community mirror of Unity Standard Assets (free)
- Scripts from the original package were removed to avoid conflicts with `AircraftController.cs`
- Use **MakerFlight RC → Bootstrap → Build Free Internal Visualization** to wire the scene
